# Apple Developer — App ID (iOS)

Usar estos valores al registrar el identificador.

## App ID

| Campo | Valor |
|-------|-------|
| Description | GymBro |
| Bundle ID type | Explicit |
| Identifier | `com.juanmamartinez.gymbro` |

## Capabilities

| Capability | Activar |
|------------|---------|
| Push Notifications | **Sí** |
| Sign in with Apple | No |
| Associated Domains | No |

## Nota

`com.gymbro.app` **no** debe usarse como Bundle ID iOS: Apple lo rechazó / no está disponible.
El package Android del proyecto permanece en `com.gymbro.app` y es independiente.
